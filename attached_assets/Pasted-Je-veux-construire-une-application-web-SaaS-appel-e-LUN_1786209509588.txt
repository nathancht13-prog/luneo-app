Je veux construire une application web SaaS appelée LUNEO.

IMPORTANT :
Je ne veux PAS commencer par une landing page marketing.
Je veux construire directement le produit / l'application.

Luneo est une application destinée aux familles qui permet aux parents de créer des histoires personnalisées pour leurs enfants.

PROMESSE DE LUNEO :
"Les histoires où votre enfant est le héros."

Le principe fondamental :
L'enfant est TOUJOURS le personnage principal de l'histoire.

Le parent crée un profil pour son enfant, puis peut créer une histoire personnalisée en fonction de son âge, de ses goûts et du type d'histoire choisi.

Luneo doit donner envie de revenir chaque soir pour lire une nouvelle histoire ou continuer une aventure.

==================================================
3. STRUCTURE DES HISTOIRES
==================================================

Il existe DEUX GRANDES CATÉGORIES.

------------------------------------------
CATÉGORIE 1 : DIVERTISSEMENT
------------------------------------------

Objectif :
Faire rêver, rire et divertir l'enfant.

Thèmes possibles :

- 🐉 Dragons
- 🦖 Dinosaures
- 🚀 Espace
- 🏴‍☠️ Pirates
- 🧙 Magie
- 🔎 Mystère
- 😂 Drôle
- 🌲 Aventure
- 🎲 Surprise

------------------------------------------
CATÉGORIE 2 : ÉMOTIONS & APPRENTISSAGE
------------------------------------------

Objectif :
Aider l'enfant à comprendre certaines situations ou émotions grâce à une histoire.

Thèmes possibles :

- 😡 Gérer sa colère
- 🤝 Apprendre à partager
- ❤️ Comprendre ses émotions
- 💪 Confiance en soi
- 😨 Peur du noir
- 🫶 Patience
- 👋 Séparation
- 🧒 Amitié
- 🌱 Grandir

IMPORTANT :

Les histoires éducatives ne doivent JAMAIS ressembler à une leçon.

L'enfant doit découvrir le sujet à travers l'aventure du héros.

Exemple :

Si le parent choisit "Gérer sa colère", ne pas écrire une histoire qui dit directement à l'enfant qu'il doit contrôler sa colère.

Créer plutôt une aventure dans laquelle le héros rencontre une situation liée à la colère et apprend progressivement quelque chose à travers l'histoire.

==================================================
4. EXPÉRIENCE DE CRÉATION D'UNE HISTOIRE
==================================================

Quand le parent ouvre le dashboard, afficher quelque chose comme :

"Bonsoir 👋"

"Quelle histoire allons-nous vivre ce soir ?"

Ajouter un bouton principal :

"✨ Créer une histoire"

Lorsque le parent clique dessus :

ÉTAPE 1 :
Afficher deux grandes cartes :

🎉 DIVERTISSEMENT
"Pour rêver, rire et partir à l'aventure."

❤️ ÉMOTIONS & APPRENTISSAGE
"Pour grandir et comprendre ses émotions."

ÉTAPE 2 :
Une fois la catégorie choisie, afficher les thèmes correspondants.

Exemple :

Divertissement :
Dragons / Dinosaures / Espace / Pirates / Magie / Drôle / Mystère / Aventure

Émotions & apprentissage :
Colère / Partage / Confiance / Peur / Amitié / Patience / etc.

ÉTAPE 3 :
Permettre de choisir :

- enfant
- thème
- longueur de l'histoire
- éventuellement une idée personnalisée

ÉTAPE 4 :
Permettre de choisir :

"✨ Nouvelle aventure"

ou

"📖 Continuer une aventure"

ÉTAPE 5 :
Afficher une page de génération.

Pour la V1, la génération peut être simulée avec des données fictives.

NE PAS encore connecter une API IA.
